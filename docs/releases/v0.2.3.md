A fix release for phones whose hotspot would not start from Untether.

**Fixed**

- "Could not start (code -1)": some phones cannot run a hotspot on 5 GHz channel 36 with WPA3,
  which Untether sets for a fast join. When that start fails, the phone now retries once on any
  band with WPA2 and keeps using that. The network's name and password stay the same, so the Mac
  still joins, just with a scan.
- After the hotspot settings were changed by hand in Android, Untether showed its own network name
  while another one was on the air, and the Mac could not join. The config is now checked before
  every start, and the app shows the name really on the air.
- The Mac could get stuck reconnecting after the phone app updated: when macOS sends no disconnect
  event, the session now ends by itself within a few seconds.

**Updating**

- Phone: install `Untether-0.2.3.apk` over 0.2.2; pairing and settings stay.
- Mac: replace Untether in Applications with the one from `Untether-0.2.3.dmg` (self-signed: on
  macOS 15 and newer allow it once in **System Settings → Privacy & Security → Open Anyway**).

**Play Protect** may still block the APK as harmful; its verdict is tied to the app's package on
Google's side. Tap **Install anyway**; the APK is built by GitHub Actions straight from this
repository.
