**Updates from inside the apps.** From this version on, Untether looks for a new release at start
and every 12 hours and offers it right where you are:

- Mac: a banner in the window, **Install**. It downloads the new version, checks that it is signed
  like the one running, puts it in place and restarts.
- Phone: a card in the app, **Install**. It downloads the APK and hands it to Android's installer,
  which asks once whether Untether may install apps, then to confirm the update.
- **What's new** opens the release page.

This release itself still has to be installed by hand.

**Your hotspot stays yours.** New installs keep the hotspot name and password set in Android (Use
Android's hotspot settings is on by default). **Randomize** gives the hotspot a new random name and
password and opens the pairing window for the Mac.

**Updating**

- Phone: install `Untether-0.2.4.apk` over 0.2.3. The app now asks for internet access, for the
  update check. Pairing and settings stay.
- Mac: put Untether from `Untether-0.2.4.dmg` in Applications (self-signed: on macOS 15 and newer
  allow it once in **System Settings → Privacy & Security → Open Anyway**). If you built Untether
  yourself before, replace it with this one: in-app updates only accept a release-signed app.

**Play Protect** may still block the APK as harmful; its verdict is tied to the app's package on
Google's side. Tap **Install anyway**; the APK is built by GitHub Actions straight from this
repository.
