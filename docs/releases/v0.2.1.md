**Signal in the menu bar.** The Untether icon now carries the phone's signal bars and network type
(3G, LTE, 5G), so you can see whether the hotspot is worth turning on before you click. Unlit bars
are dimmed; **Settings → Signal in the menu bar** hides them.

**Also in this release**

- Android: the hotspot is controlled from a Shizuku user service, a separate process that runs as
  the shell user. The app no longer ships a hidden API bypass library, and the APK no longer carries
  Google's encrypted dependency list.
- macOS: the mark sits on one line with the bars and the label.

**Updating**

- Phone: install `Untether-0.2.1.apk` over 0.2.0, pairing and settings stay. A build you made
  yourself has a different signature: uninstall it first and pair again.
- Mac: replace Untether in Applications with the one from `Untether-0.2.1.dmg`. It is self-signed,
  not notarized: the first launch needs a right-click → **Open**.

**Play Protect** may still block the APK as harmful. Its verdict is tied to the app's package on
Google's side, not to the code, and stays until Google reviews it. Tap **Install anyway**; the APK is
built by GitHub Actions straight from this repository.

**Known limits.** Tested on a Pixel 9 with Android 17; Android 12–16 are expected to work but have not
been tried on a device yet.
